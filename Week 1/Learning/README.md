# Day 1 - Python Fundamentals

## Task 1: Swapping Two Numbers

### Task Description

Swap two numbers without using a third variable.

### Additional Practice

To understand different approaches to swapping values, I also practiced:

- Swapping using a temporary variable.
- Swapping using arithmetic operations without a third variable.
- Swapping using the XOR (`^`) operator.
- Swapping using Python's tuple unpacking method:
  `a, b = b, a`

### Learning Outcomes

Through this task, I learned different variable-swapping techniques in Python. I practiced variable assignment, arithmetic operators, bitwise XOR operators, and tuple unpacking. I also learned that the same problem can be solved using different approaches and compared their readability and efficiency.

### Key Takeaway

Python's tuple unpacking method, `a, b = b, a`, is the simplest and most readable approach for swapping two variables.
