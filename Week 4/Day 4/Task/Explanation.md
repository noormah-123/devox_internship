🔹 Explanation: 
The sigmoid function takes any number — big or small, positive or negative — and squeezes it into a value between 0 and 1.

If the input is a big positive number, the output is close to 1.
If the input is a big negative number, the output is close to 0.
If the input is 0, the output is exactly 0.5.
Because of this behavior, sigmoid is perfect for probability-based predictions — like classifying whether an email is spam, whether a tumor is malignant, or whether a student will pass.

It’s also used as an activation function in neural networks, helping the model decide whether a neuron should "fire" or not.
