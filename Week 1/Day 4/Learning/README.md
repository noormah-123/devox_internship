# Function Library: Converters and Calculators

This project contains a small Python function library that demonstrates the use of reusable functions for temperature conversion, area calculation, distance conversion, and basic mathematical operations.

## Tasks

### Task 1: Temperature Converter and Area Calculator

Created reusable functions for temperature conversion and area calculation.

#### Temperature Conversion

* Celsius to Fahrenheit
* Fahrenheit to Celsius

#### Area Calculation

* Circle area
* Rectangle area

The built-in `math` module is used for the value of π (`math.pi`) when calculating the area of a circle.

### Task 2: Distance Converter

Created reusable functions to convert distances between different units.

Conversions included:

* Kilometers to Miles
* Miles to Kilometers
* Meters to Kilometers

### Task 3: User Input Calculator

Created a simple calculator that takes input from the user and performs basic mathematical operations.

Operations included:

* Addition
* Subtraction
* Multiplication
* Division

The calculator uses functions for each operation and conditional statements to perform the selected calculation.

## Concepts Used

* Functions
* Parameters
* Return values
* User input using `input()`
* Type conversion using `float()`
* Conditional statements (`if`, `elif`, and `else`)
* Mathematical operators
* The built-in `math` module
* Code reusability
* Division-by-zero handling

## Purpose

The purpose of this project is to practice creating reusable functions and organizing related calculations into a small function library. The project demonstrates how functions can be created once and reused multiple times with different input values.
